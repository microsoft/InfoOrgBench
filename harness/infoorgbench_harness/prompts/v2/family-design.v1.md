The records are design documents and their metadata files from a software project's feature-proposal process. Organize them by the group that owns each proposal, then by proposal.
- Create one folder for each group that owns proposals and, inside it, one folder for each proposal that group owns.
- Put all records that belong to the same proposal, such as its design document and its metadata file, in that proposal's folder.
- Folder names are not prescribed; choose short descriptive names.
